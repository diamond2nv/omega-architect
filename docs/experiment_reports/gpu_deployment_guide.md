## 模型规格

| 模型 | 参数 | FP16 显存 | 4-bit 显存 | 建议 GPU |
|:----|:----:|:---------:|:----------:|:---------|
| DeepSeek-Prover-V2-7B | 7B | ~16 GB | ~8 GB | 单卡 24 GB |
| DeepSeek-Prover-V2-671B (MoE) | 671B (37B active) | ~400 GB | ~120 GB | 8×A100 80GB |

> **结论**: 7B 版本对国内用户最可行。671B 需要企业级集群，不在本推荐范围内。

```

- GPU:     RTX 4090 24GB × 1

- 镜像:    PyTorch 2.5 + CUDA 12.4 (预装)
- 环境:    vLLM 一键部署
- 费用:    ¥1.98/时 ≈ ¥47/天 ≈ ¥950/月（包月卡）
```

**AutoDL 优势**:
- 学术圈出身，高校用户多，社区资源丰富
- 注册送 1 月会员，学生认证永久优惠
- 按秒计费，关机保留数据 15 天
- 预装镜像开箱即用，无需配置环境
- RTX 4090 国内占比 60%+，社区支持最强

**部署方式**:
```bash
# AutoDL 镜像（已预装 PyTorch + CUDA）
pip install vllm
huggingface-cli download deepseek-ai/DeepSeek-Prover-V2-7B
vllm serve /root/autodl-fs/DeepSeek-Prover-V2-7B \
  --port 8001 \
  --max-model-len 8192 \
  --gpu-memory-utilization 0.9 \
  --dtype bfloat16 \
  --enforce-eager
```

## 与 WSL RTX 4500 Ada 的对比

| 指标 | 当前 WSL | 推荐方案（AutoDL 4090） |
|:----|:--------:|:----------------------:|
| GPU | RTX 4500 Ada 24GB | **RTX 4090 24GB** |
| FP16 算力 | 59 TFLOPS | **82 TFLOPS (+39%)** |
| vLLM | 不支持（WSL 兼容问题） | ✅ 原生支持 |
| max-model-len | **4096（瓶颈）** | **8192+（翻倍）** |
| 网络 | 国内 GitHub 超时 | **国内网络通畅** |
| 成本 | 已有（闲置） | ¥1.98/时 或 ¥950/月 |
| 准备时间 | 已部署 | **1 小时上手** |

我们的 WSL 环境跑 7B 模型最大的问题是 `max-model-len=4096`，且 vLLM 在 WSL 下有兼容性问题。AutoDL 的 4090 可以直接解决这两个瓶颈，并且在 8K context 下 Prover-V2-7B 应该能正常输出完整证明。
